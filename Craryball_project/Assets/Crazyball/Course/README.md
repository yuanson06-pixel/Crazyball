# Cumulative Course Scene

Create and edit these scenes through the Unity Editor:

- `Scenes/Crazyball_Main.unity`
- `Scenes/Crazyball_Course.unity`

`Crazyball_Course` starts from a copy of the original Crazyball Game scene with its legacy gameplay logic disconnected. Students progressively assemble the supplied components in this one scene.

Do not create lesson-by-lesson scene copies. Do not edit scene YAML or existing `.meta` files directly.
